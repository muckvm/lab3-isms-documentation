# Репозиторий документации СМИБ

## Назначение

Данный репозиторий предназначен для ведения документированной информации системы менеджмента информационной безопасности (СМИБ).

Использование Git позволяет контролировать изменения документов, сохранять историю редакций, определять авторов изменений и идентифицировать утвержденные версии документов.

## Структура репозитория

- `01-politika` — политика информационной безопасности верхнего уровня.
- `02-chastnye-politiki` — частные политики информационной безопасности.
- `03-procedury` — процедуры и регламенты.
- `04-instrukcii` — инструкции, шаблоны и чек-листы.
- `05-zapisi` — шаблоны записей.

## Порядок внесения изменений

1. Изменения выполняются в отдельной ветке.
2. Каждое существенное изменение фиксируется отдельным коммитом.
3. Коммит должен содержать информативное описание изменения.
4. Изменения отправляются в удаленный репозиторий.
5. Для включения изменений в основную ветку создается запрос на слияние.
6. Изменения проходят рецензирование.
7. Утвержденные редакции документов отмечаются тегами Git.
